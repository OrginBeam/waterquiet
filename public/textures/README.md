# WaterQuiet 方块纹理

**有图用图，无图用噪声**——每个方块对应一张 PNG，放进本目录即可覆盖默认的程序化噪声纹理。没放文件的方块自动用噪声生成，风格统一、无需凑齐全部。

## 怎么用

1. 在 `public/textures/` 下放一张 32×32 的 PNG（命名见下表），例如 `stone.png`
2. 刷新游戏：石头方块立即换成你的贴图，其余方块仍是噪声
3. 想画哪个画哪个，随时可以补，互不影响

> 图片编辑器导出时：尺寸 **32×32**，PNG 格式，不要缩放。

## 无缝平铺要点

噪声纹理本身已按 32 像素周期无缝生成。**手绘时**注意：
- 每张图的左边缘要与右边缘能自然接上（上下同理），否则方块之间出现接缝
- 主色调贴近上表底色，避免和 hotbar 色块、世界观风格冲突
- 草方块侧面：上半草皮、下半泥土，交界用噪声起伏（参考噪声版的 `grass_side`）

## 多面方块

- **草方块**：顶用 `grass_top`、侧用 `grass_side`、底用 `dirt`
- **原木**：顶/底用 `wood_top`、侧用 `wood_side`
- 其余方块六面同纹
